Important source distinction. The existing Cloudflare Agent Bridge has no HubSpot API credential. It fetches the latest published, sanitised Cedwyn task-index file (with a short edge cache), not the live HubSpot CRM directly. The panel above therefore refreshes the latest published project mirror on page load; the full-portal figures remain the dated native search snapshot until a dedicated HubSpot private-app credential is authorised for a server-side Worker.

Parcel reference. Slot 37 is a digital Cedwyn site-area index. It is not a historic tithe-apportionment plot number and does not assert land ownership, boundaries or legal equivalence. The historic plot remains unassigned pending verification against EV-0215.
Data handling. This page is read-only. The browser requests paginated metadata through the existing Agent Bridge and calculates counts locally. It does not request task bodies, create tasks, edit statuses or expose credentials.
