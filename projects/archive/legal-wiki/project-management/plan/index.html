Repeatable cycle

On each inbound item or scheduled run: preserve → catalogue → update case ticket → associate task to WP/project → calculate deadline → set priority/owner/next action → verify acceptance → record lesson and next review. Use a stable source reference/message ID and, where available, file hash to avoid repeat work. A new event reopens the loop. An automation or agent must record that the cycle ran; never imply background monitoring without a run record.
