Goodreads and StoryGraph listings for self-published e-books

Harvested 2026-10-26 by the skills harvest. Free reader-catalogue listings; no outreach, no paid giveaways.

Why

  • Goodreads: "more than 18 million books are added to Want to Read shelves" every month; shelving a book signs the reader up for alerts (Goodreads Deals price drops, US only; giveaway emails). A listing is a place readers can find, shelve and review the book. (goodreads.com, Apr 2018 - old figure, Goodreads' own)
  • The Goodreads Author Program is free "for any author, anywhere in the world" with a published book in the database: claimed profile, Author badge, bio, Ask the Author, blog feed, book-listing fixes. (goodreads.com)
  • Giveaways are paid ($119 Standard for up to 100 Kindle e-books or print, US-run; $599 Premium) since Jan 2018 -> outside our zero-spend rule. (goodreads.com; janefriedman.com)
  • StoryGraph (the growing alternative): "all new books need to be added to the site manually", any user can add one, partial records are completed by volunteer librarians; ISBN optional; "Not a book" box exists for non-book material. (thestorygraph.freshdesk.com article 79000141991, updated 18 Sep 2025)

Rules that bite

  • Goodreads: ordinary members can no longer add brand-new books themselves in many cases; requests go to the Goodreads Librarians Group, "Adding New Books" folder (help.goodreads.com Q&A; r/goodreads thread 153afsi). Search by ISBN/ASIN first to avoid duplicates. Librarians need: title, author as on the cover, publisher, date, format (ebook), page count, language, a link to a page where it is sold or described, cover image.
  • One record per work; each edition (v0.01 free, v0.02 paid; English/Welsh/Spanish) is an edition of that work, not a new book.
  • Authors must not review or rate their own book or ask people to; reviews come only from readers (see reviews-social-proof-direct-ebooks.md).
  • Corporate/archive authorship is allowed (author field = the name on the cover). Claiming an author profile needs the account of the named author.

How-to (about 30 minutes per book, once)

  1. Check each title on Goodreads and StoryGraph search (title + "Great House Farm"). Record "absent / present" in the project workspace
  2. Prepare a listing sheet per book: exact cover title, author as printed, publisher (the imprint name used on the cover), edition date and version, page count from ebooks.json, language, one-paragraph neutral description (no banned words), cover JPEG, the Cedwyn /ebooks/ page URL as the source link.
  3. StoryGraph: add directly at app.thestorygraph.com from a Tab-owned reader account; set format = digital; add the Welsh/Spanish editions via Editions > Add Edition when those exist.
  4. Goodreads: from a Tab-owned reader account, post one request per book in the Librarians Group "Adding New Books" folder with the sheet. Wait for the librarian; don't double-post.
  5. Once listed, add the Goodreads and StoryGraph links to each book's /ebooks/ page as "Shelve it on..." (these are reader-catalogue links, not purchase routes; purchases stay via /ebooks/).
  6. Monthly: note shelvings ("want to read" count) and ratings per book in the growth notes.

How we apply it to Cedwyn

  • Candidates: the four current e-books (Wiki, FCG, Dartboard, Projects) and the bundle is NOT listed (Goodreads lists works, not shop bundles).
  • Author field: use the name printed on the covers. If a cover carries a personal name, stop and ask the root first: public text never names the project lead, and claiming a Goodreads Author profile would need his decision. An archive/imprint name ("Cedwyn") avoids that.
  • Titles containing a banned word are titles, not our wording; the descriptions we write must still pass the banned-words check.
  • Accounts: a Tab-owned reader account per site (Tab mail), credentials in the vault; record in the project workspace No DMs, no group self-promotion, no giveaways (paid).
  • Expected effect: small and slow (discovery + social proof), but permanent and free; it also gives AI/search engines a third-party record of the books.
