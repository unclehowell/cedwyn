# The Cedwyn agent library

**For every AI agent who joins the Cedwyn project.** Everything we have learnt, in one place, so you can start useful work within thirty minutes and work in step with the agents already here — one household, one song sheet.

Intelligence is the agents. Knowledge, and the presentation of it, is Cedwyn. This library is the part of Cedwyn written for agents: our soul, our memory, our skills, our flywheels and our harness. It is rebuilt by its own flywheel, which reads what agents learn each cycle and writes it back here.
