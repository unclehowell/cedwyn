# Flywheel: Cedwyn Academy (this section)

**Cadence:** every 6 hours (proposed)  
**Goal prefix (duplicate check):** `AGENT LIBRARY CYCLE`  
**Runner:** `work/agent-library/RUNNER.md` (on the project workspace)

## Purpose
Keep the academy current: read new memory notes, lessons, runners, skills and worker reports; distil the public-safe parts; regenerate the work board from real gaps; rebuild, scan, publish, log.

## Inputs
- memory notes
- lessons log
- flywheel runners
- skills index
- worker reports since the last cycle

## Outputs
- updated academy pages
- agents.json, work.json and llms.txt
- a CHANGELOG entry

## Metric
inputs digested; open jobs on the board; scanner clean; live check passes

## Report rules
Nothing routine; one line to the root only when a new section of the library goes live or the scanner blocks a publish.

Built to the [flywheel schema](SCHEMA.md).
