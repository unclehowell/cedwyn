# Flywheel: Growth flywheels (on-page, quote pack, visibility, weekly report)

**Cadence:** weekly (Mon 07:30 visibility, Tue 19:00 quote pack, Wed 13:30 on-page, Sun 18:00 report)  
**Goal prefix (duplicate check):** `CEDWYN ONPAGE RUN / QUOTE PACK RUN / VISIBILITY CHECK RUN / GROWTH REPORT RUN`  
**Runner:** `work/cedwyn-growth/*/RUNNER.md` (on the project workspace)

## Purpose
Make Cedwyn findable and shareable: markup audits, quote cards from the records, search and AI visibility checks, and a weekly measured report.

## Inputs
- traffic, followers, sign-ups, sales, Search Console
- the records and e-books

## Outputs
- markup fixes
- quote cards and posts
- visibility scores
- the weekly three-line report

## Metric
traffic, followers, sign-ups, sales week on week

## Report rules
The Sunday report is the one routine message; otherwise only a sale, a post over 1,000 views or a blocker.

Built to the [flywheel schema](SCHEMA.md).
