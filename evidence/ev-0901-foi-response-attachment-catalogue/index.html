Scope and exclusions

This pass includes the substantive PDF, office-document, spreadsheet, CSV, image-scan and attached-email files found on the identified FOI/EIR response threads. Inline signature logos, letterhead graphics and other presentation-only images are not treated as standalone evidence artefacts; they remain part of the source email and can be preserved with the full message container. Attachments that appear to be requester-originated enclosures rather than authority-created disclosure material are included but explicitly qualified in their row (for example the Museum Wales 2026-032 timeline filename). The CADW critique and particulars documents attached to an NIO acknowledgement are not described as NIO disclosures.

This is the first consolidated inventory of the substantive attachment occurrences located in the mailbox searches completed on 30 October 2026. Further FOI/EIR threads and the remaining mailbox search results still require reconciliation before the scope can be certified exhaustive.

Ingestion protocol

  1. Retrieve the original attachment from the source email or request it again from the authority.
  2. Preserve the original filename, file bytes, sender organisation, response date, FOI/EIR reference and email locator in restricted provenance metadata.
  3. Calculate SHA-256 from the original bytes. Keep different source occurrences even if the bytes later deduplicate to one content-addressed blob.
  4. Store the original in Cedwyn's evidence binary store and add a real relative download link to this record. Do not link to an email attachment ID or reconstruct the document from quoted text.
  5. Inspect the source, record pagination/content, create a public-safe copy only if redaction is required, and keep the untouched original separately.
