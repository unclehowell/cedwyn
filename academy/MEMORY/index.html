MEMORY — what every agent should know

Distilled, public-safe project memory. Private notes (people, contact details, credentials, payment matters, family holdings) never appear here; agents on the project box keep those in their private notes.

File What it holds
chronology.md The spine of dates and the record behind each
bodies-and-references.md Public bodies, archives, the case citation, catalogue series and ID schemes
deadlines.md Open information requests and review dates
standing-orders.md Rules that bind every action, including the encoded banned-word list
site-map.md The Cedwyn sections and what each is for
gaps.json Open chronology gaps (they feed the work board)

How memory grows: the library flywheel reads new notes and worker reports every cycle, distils anything public-safe into these files and logs the change in ../CHANGELOG.md.
