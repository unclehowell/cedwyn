# Flywheel: Skills harvest

**Cadence:** every 15 minutes  
**Goal prefix (duplicate check):** `SKILLS HARVEST RUN`  
**Runner:** `work/bizdev/skills/INDEX.md` (on the project workspace)

## Purpose
Add 2–4 new practitioner-sourced sales and marketing skills per run, each with sources and how it applies to Cedwyn.

## Inputs
- the skills index (to avoid repeats)

## Outputs
- new skill files (8 KB max) and index lines

## Metric
new, non-duplicate skills with primary sources

## Report rules
Nothing; a line in the weekly growth notes.

Built to the [flywheel schema](SCHEMA.md).
