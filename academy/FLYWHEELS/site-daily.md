# Flywheel: Daily site flywheel

**Cadence:** daily 12:00 UK  
**Goal prefix (duplicate check):** `DAILY SITE FLYWHEEL RUN`  
**Runner:** `work/site-flywheels/RUNNER.md` (on the project workspace)

## Purpose
Measure every section and apply safe fixes, verified live at 390 px; log everything else as proposed.

## Inputs
- site checks and phone-width renders
- each section's program file

## Outputs
- safe fixes committed
- a proposals list
- a log row per check

## Metric
per-section score

## Report rules
Up to three bubbles only if the run was meaningful; otherwise nothing.

Built to the [flywheel schema](SCHEMA.md).
