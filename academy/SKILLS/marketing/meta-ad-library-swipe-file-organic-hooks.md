# Meta Ad Library as a free swipe file (organic research only, no ads bought)

Date: 30 Oct 2026 · Area: Facebook/Instagram growth, copy, CRO · Spend: £0 (research only)

## What it is
The Meta Ad Library (facebook.com) is a public, free, no-login search of ads that are running on Facebook, Instagram, Messenger and Audience Network. You can search by advertiser or keyword, filter by country and platform, and see each ad's creative, copy, CTA button and "Started running on" date. We use it to learn which messages, formats and proof points peers keep paying for. We never run ads from it.

## Facts we have, and how well they are checked
- **Longevity is a hint, not proof.** Markifact analysed 40 active ads from 8 DTC brands (pulled 20 Jul 2026, published 21 Jul 2026, page read): active for 30+ days 26/40, 60+ days 18/40, 90+ days 11/40, 120+ days 8/40; median 47 days, range 6–171. Their own warning: "it does not prove they were profitable".
- **Brands repeat a few messages in many variants.** Same study: 40 ads carried only 23 unique primary messages, and 17 reused a message. One brand ran one message across all 5 sampled ads.
- **Proof beats cleverness.** 23/40 had a numeric proof point (quantity, price, review count). 22/40 spoke to the reader ("you/your"). Only 12/40 led with an offer or discount. CTA: 37 "Shop Now", 3 "Learn More".
- **Agency rule of thumb (Commit Agency, page read):** "If an ad has been live for three months, assume it's delivering results". Dozens of small variants usually means the brand is A/B testing. That's opinion, not data. Use runtime only to decide what to look at first.
- **UK scope (not checked against Meta's own page; Meta's help and transparency pages answered 400/403 to a plain fetch).** Search snippets (adtribute.io; a 2026 guide) say that for the UK the Library shows **only currently active** commercial ads, and the Ad Library API covers commercial ads only for EU delivery. Political/issue ads are covered everywhere. So for UK peers: browse the web UI and snapshot what you see. Ads that stop are gone from view, and there's no API.

## How to do it (30 minutes a month)
1. Go to facebook.com Set Country = United Kingdom (then repeat with Argentina for the Patagonia side), Ad category = All ads, Platform = all.
2. Search **advertisers** first, then **keywords**. Keyword search matches ad text, so try reader words, not trade words (see the Cedwyn list below).
3. For each advertiser, open "See ad details" and record in a sheet: advertiser · started date · days active · format (image/video/carousel/DCO) · hook (first line) · proof point · CTA · landing page type · number of variants of the same message.
4. Sort by days active. Read the top 10 closely. Ignore anything under 14 days.
5. Code each long-runner's hook into a type: question / number / "you" / curiosity gap / place name / date / quote from a record.
6. Write **one** organic test per month from the most common long-running hook type: a Reel caption, a carousel first slide, or the /ebooks/ card's first line. Keep the message and change one variable (Markifact's "change one meaningful variable at a time").
7. Measure on our side only: non-follower reach and link clicks on the post, and /ebooks/ clicks with a UTM. Compare 4+ posts per hook type before calling it.
8. File a snapshot (screenshot path + URL + date) because UK ads vanish when paused.

## Rules
- Research only. No paid ads (standing rule). No copying creative, images or exact wording: borrow the *structure* (hook type, proof type), never the words.
- Don't message advertisers. Don't scrape at volume; browsing the UI by hand is fine.
- Opinions (e.g. "3 months means it works") are labelled as opinions in anything we publish internally.

## How we apply it to Cedwyn
- **Peers to search (UK):** history and heritage publishers and e-book sellers, family-history services, Welsh-interest booksellers and heritage attractions, museum shops, history magazines' subscription ads, and local-history podcasts. Keyword seeds: "Welsh history", "family history", "local history book", "Patagonia", "Glamorgan", "Cardiff history", "old farm", "ancestors", "heritage ebook".
- **Argentina pass:** "Gales", "galeses Chubut", "Patagonia historia", "Trelew", for the Spanish-language Welsh–Patagonia material.
- **What we'd lift (structure only):** if long-runners in heritage lead with a dated record line plus a number (e.g. "1824: 139 acres…"), that matches our quote-card format. Test it as the first slide of the weekly quote carousel and as the /ebooks/ card hook, against our current first line, over 4+ posts each.
- **Proof points we can honestly use:** page counts, number of sourced records, archive references, free v0.0.1 edition. Never "was/saving" assertions, and prices only as listed (v0.0.1 free, v0.0.2 £4.99, bundle £19.96).
- **Output:** the project workspace (one row per ad), plus one line in the Sunday growth notes naming the hook type tested that month.
- **Owner steps:** none. No login is needed for the Library.
- **What would change this:** if Meta's own page shows UK inactive ads are kept (as for the EU), add a "stopped" column and use stop dates as a signal too.
