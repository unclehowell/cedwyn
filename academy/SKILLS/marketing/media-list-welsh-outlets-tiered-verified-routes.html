Media list for Welsh outlets: build, tier and keep it (PR)

Skill harvested 30 Oct 2026. Distinct from: letters-to-the-editor-local-press-wales.md (letters), op-ed-guest-opinion-pitch-wales-named-byline-gate.md (opinion), local-democracy-reporters-ldrs-council-records-press-route.md (LDRs), welsh-language-media-papur-bro-golwg360-heno.md (Welsh-medium), press-requests-and-mention-monitoring.md (inbound requests/monitoring), online-press-kit-page-heritage-ebooks.md (press kit). This file is the list itself: who, which beat, which route, when last contacted.

Why a list beats a blast (numbers)

  • Cision 2025 State of the Media (press release, read 30 Oct 2026): 86% of journalists immediately reject a pitch not aligned with their beat or audience; 72% name press releases as the most useful thing PR can give; 85% say the best way to start a relationship is a plain introductory email, even with no story; 72% worry about factual errors in AI-written PR content.
  • Muck Rack State of Journalism 2025 (PDF blocked this machine; figures from its search preview, not read in full): 62% prefer 1:1 email pitches; red flags include "overly promotional" (71%) and "looks like a mass email" (50%).
  • Lesson: a short list of the right desks, each pitched one-to-one, beats a long list. Relevance is the filter, not reach.

How to build it (about 60 minutes, then 10 minutes a month)

  1. Columns (one row per desk or named journalist): outlet, tier (1 local / 2 national Wales / 3 Welsh-language / 4 specialist/heritage), desk or person, beat (one line from their last 3 bylines), route (newsdesk email / named email / web form), source URL where you found the address, date verified, language (en/cy), last contacted, status (none / intro sent / replied / covered / declined / do-not-contact), notes.
  2. Start from the patch, not the nation: the closest local paper covers the parish; national Wales outlets pick up what local papers run.
  3. Read the last 3 pieces by each journalist before adding them. Write the beat in your own words. No recent heritage/local-history/land piece = leave them out.
  4. Only addresses you found on the outlet's own page (or the journalist's own byline/profile). Record the URL and date. Re-verify any address older than 90 days before use.
  5. Tier and cap: tier 1 is 2-4 rows, tier 2 is 3-6, tier 3 is 2-4, tier 4 is 3-6. A list over 25 for a local heritage story means relevance has slipped.
  6. Do-not-contact column is binding: anyone with an open thread, anyone who declined, and anyone on a standing exclusion list.
  7. Hygiene: one person once per story; log every contact the same day; no follow-up within 5 working days; one follow-up maximum.

  • Nation.Cymru: news stories and press releases to [address kept in the project workspace] ("picked up by whoever is working at the time"); flag any date-sensitive item in the email; audience "over one million readers a month" (their own figure). Source: nation.cymru
  • Welsh-medium outlets (Golwg360, papurau bro, Heno): see welsh-language-media-papur-bro-golwg360-heno.md; add their rows from that file with the same columns.
  • Not checked today: BBC Wales news desk (the BBC "share your story" page is UK-wide), Western Mail print desk, specialist heritage magazines (see history-magazine-journal-articles-historian-history-today.md).

The pitch each row gets (one-to-one, not BCC)

  • Subject: the news in under 10 words, place name first (e.g. "Llandough: 765 farm records now searchable online").
  • Body: 3 short paragraphs: what is new and why now; one strong record with its date and archive reference; link to the press kit page and one image with credit line. Plain text, no attachments on first contact.
  • Welsh-language desks get the pitch in Welsh (or bilingual), not an English pitch with an apology.

How we apply it to Cedwyn

  • Gate: press only on the project lead's GO (standing rule). Build and verify the list now as a HubSpot record/CSV; send nothing. Any pitch is a HubSpot draft task in the hive format, never a Gmail send.
  • Store the list at the project workspace (create on first use) and check it with tools/media_list_check.py before any GO.
  • Tier 1 for Cedwyn: Penarth Times + Barry & District News (Llandough sits between them). Tier 2: WalesOnline, Nation.Cymru. Tier 3: Golwg360 + the local papur bro. Tier 4: heritage magazines/journals from the existing skill files.
  • Story hooks that fit beats: the searchable evidence catalogue (765 items), the documentary scenes, Welsh-language place-name records, Llandough history talks.
  • Pitch copy must pass the editorial rules: neutral third person; never name the project lead; never call the family "tenant farmers"; none of the banned words (states, assertions, per, second-hand report, not checked, reported, deception, taken); no accusations about named people; nothing about family holdings or addresses.
