# Facebook Events on the existing Page for an online (or library) talk

Read 26 Oct 2026 on Meta's Help Centre. Status for Cedwyn: PROPOSAL (a public event page = a new public page and a date commitment; owner GO on the talk itself). Complements free-online-talk-listings-eventbrite-meetup.md (Eventbrite/Meetup) and the library/history-society talk routes; this file covers only Facebook's own event tool.

## What the tool does (Meta Help Centre, read)
- All events hosted by Pages are public. Create: switch into the Page > Events > + Create new event > name, date/time, In person or Virtual > details > Create event. (help 116346471784004)
- Online format choices: Facebook Live, External link, or Other. Editable later: name, date/time (up to a couple of days before), online format, online/in-person type, location, description, cover photo, guest-list visibility, co-hosts. NOT editable: privacy, the guests-can-invite setting, ticket cost. Paid events are Page-only. If something fixed is wrong, cancel and recreate, losing RSVPs. (help 845829532845585)
- Co-hosts: a Page can add other Pages or profiles as co-hosts; the co-host must accept, then shows on the event and becomes an event admin once it RSVPs Interested/Going. Unaccepted requests stay "pending" and do not show publicly. (help 100368793838002)
- Off-Facebook invites: a host can invite non-users by email or phone; they get a link, can RSVP, and then get event updates (time/place changes); they can unsubscribe or block the host. (help 634748235078871)
- Recurring Page events exist (related article title; not read).

## How to run one (zero spend)
1. Fix the settings that cannot be edited BEFORE creating: Public, guests may invite friends ON, free (no ticket).
2. Name = searchable plain words: "<Place> history talk: <topic> (online)". Cover 1920x1005-ish image with the date in the art. Description: first line = what and when (UK time + Argentina time for Patagonia readers), then the link, then the free chapter link with UTM (utm_source=facebook&utm_medium=event&utm_campaign=<talk-slug>).
3. Online format: External link (Zoom/Meet/YouTube Live), or Facebook Live if the talk is streamed from the Page. External link keeps the recording ours.
4. Co-hosts: only partner Pages that have agreed in advance (a library, history society, Welsh Patagonian society). Their acceptance puts the event on their Page and in front of their followers; never add a Page cold.
5. Timeline: create 3-4 weeks out; one event-discussion post a week (an archive image + a question); a Reel or carousel linking the event 1 week out; a reminder post the day before; "starting in 1 hour" post on the day.
6. After: post the recording link and the free-chapter link in the event discussion (every Interested/Going guest is notified of host posts, Meta's design; reach not measured).
7. Off-Facebook invites by email: only to people on our own list who opted in to talk news (PECR); otherwise do not use it.
8. Measure: Interested/Going counts, attendance on the call, event-UTM sessions, signups and sales within 7 days. Keep the format if attendance >= 30% of Going and at least one signup per 10 attendees.
