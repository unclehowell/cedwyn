Mail data access

The former multi-host mail application advertised live search, individual-message endpoints, bulk export and an OpenAPI document. Those dynamic API services have not been migrated as running endpoints in the consolidated Cedwyn site.

Supported route

Use the static, read-only correspondence viewer. It reads the preserved catalogue and opens archived text where the source survives. Missing text is reported as unavailable.

Legacy API URLs

Old links to the API guide, catalogue endpoint, OpenAPI file, search, message and export endpoints are directed here or to the viewer so they do not leave a visitor at an unexplained 404. They should not be treated as a live API contract.
